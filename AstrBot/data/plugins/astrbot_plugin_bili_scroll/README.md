# 大肥龙刷B站

与本仓库主动插件一同部署，直接使用 AstrBot 已配置的对话模型，不需要B站账号和额外服务。

## 控制台

在 AstrBot「插件」找到 `astrbot_plugin_bili_scroll`，打开「大肥龙刷B站」页面。

1. 「浏览并预览」填兴趣词或留空看热门：只取视频资料并展示示例文案，不发送QQ消息
2. 开启刷B站后，可在聊天里说「大肥龙，找个动画视频给我看看」；也保留 `/刷B站 动画` 和 `/刷B站` 便于直接使用。群聊遵守既有唤醒规则
3. 定时分享默认关闭。需要时勾选群和好友，设定独立于普通主动消息的分享间隔与免打扰，再打开「定时分享」保存
4. 每个目标分别计时与去重，不会因为第一个对象拿到视频就不给第二个发。新选择或修改间隔后等一个完整间隔，取消选择会取消待发送任务。失败等待下一周期，避免重复轰炸
5. 实际分享文案由模型按标题/简介生成，俏皮卖关子；原视频URL由代码添加。已启用的二次审阅仍生效，改写不得丢失或替换URL
6. 成功发送的最终文案和链接进入当前会话的主动消息记忆，重启后仍可接话；不带到其他聊天或已重置的对话

匿名接口可能拒绝请求。插件会说明受限原因；拿不到评论时只使用标题简介。没有匹配视频或全部已分享过就跳过，不假装成功。面板预览不调用配文模型，所以展示通用预览文案，实际发送时才生成个性化文案。

本插件依赖同仓库的 `astrbot_plugin_proactive_agent` 共用会话隔离与记忆模块。二次模型审阅仍是可选项；关闭审阅不关闭收件人检查。插件数据由 AstrBot 管理，不应上传至GitHub。
