# 大肥龙刷B站 1.2

与同仓库主动插件一起部署，使用 AstrBot 配置的模型。控制台侧栏或插件页面打开「大肥龙刷B站」，全部功能在这里设置。

## 搬屎与普通搜索

默认是原版赤石/搬屎玩法：从原版关键词池、UP名单近7天投稿、最新、MyGO、相关推荐召回；默认UP名单可自行修改或清空。每次最多核验48条候选热评，候选缓存5分钟，账号/模式/关键词/名单不同不混用缓存。

必须同时满足：热评@率至少30%、视频至少45秒、出现投喂话术。评分沿用上游权重：@35、纯@15、时长30、投喂10、抽象5、评论量5；UP来源+12、连载+8、MyGO+6、3天内+5，普通吃播等美食标题每项-15（最多-30）。时长奖励以2至15分钟最高。只有已读评论才算证据；没有合格视频就跳过，不拿普通热门凑数。面板显示样本数、比例与热评片段。

默认文案一本正经地反话安利“精神食粮”，不写普通推荐摘要。可选“编造诱饵”仅用于动漫、游戏、虚拟乐队等娱乐梗。分享始终使用原始 bilibili.com 视频网址。模型只读标题、简介、评论，不声称实际看完视频。

选择「普通搜索」可正常找视频；普通模式留空看热门，搬屎模式留空用原版词池。「浏览并预览」始终只读，不调用配文模型、不发QQ消息、不执行账号写操作。匿名热评当前经常只有3条，比例只代表可见样本；登录也不保证接口一定返回更多。

## 可选扫码登录

1. 在「B站账号」点「扫码登录」，用哔哩哔哩App扫码并在手机确认；二维码过期后重新获取。
2. 看到已登录昵称和UID后，勾选「使用已登录账号浏览」并保存，后续选片才使用登录态读取。只扫码不会自动开启任何写操作。
3. 不想登录就不勾选；已登录也可取消勾选切回匿名浏览。点「退出本机登录」会停止本轮并删除本机登录凭据，不等于注销B站账号。
4. 登录过期请重新扫码。限流、权限或风控失败会显示原因，不绕过验证、不自动重试写请求。

凭据位于运行目录 `AstrBot/data/plugin_data/astrbot_plugin_bili_scroll/account-login.json`。Windows使用当前系统账号的DPAPI保护；Linux为权限0600文件（建议磁盘加密，备份应加密），不是跨机器可移植登录。凭据不进入插件设置、模型提示、接口返回或日志，不提取浏览器Cookie。依赖 `qrcode[pil]>=8,<9`，项目安装流程已包含。

## B站账号玩法（全部默认关闭）

- 自动评论：填写最多5个**精确B站昵称**，不带@，逗号分隔；保存后先点「核对已保存的@名单」，查看解析的UID。每轮在合格视频下发短文案并@名单；昵称无法唯一匹配就不发布。模型不能指定收件人；普通QQ聊天不会触发这些写接口。
- 私信：填写接收者**B站UID**，不是QQ号。「只私信」禁用本轮所有公开评论和回评；「私信+已开启的评论」分别执行。每轮视频数默认1，最多5。没有配置收件人不能开启。
- 收藏：读取本人收藏夹后填ID，留空关闭；每轮先核对归属，只添加，不创建或删除收藏夹，不移除已有收藏。
- 回评：只处理本账号近7天、最近8条由插件发送的根评论下的直接回复，核对根评论作者。只接轻松互动，每轮默认1条、最多5条；同一人同一根评论最多回复一次。不扫描全站、不让评论指挥账号操作。
- 巡航：关闭/自定义/普通30分钟/高频5分钟；与QQ每对象定时独立，共用免打扰时段。启用或修改周期后等完整间隔，不立刻补发。
- 「按已保存设置跑一轮」会真实执行已开启的B站账号操作；它不向QQ发消息。仅想试选片用上面的预览。「停止本轮」不会关闭下轮巡航，需要停止定时请将巡航设为关闭后保存。

操作记录保存在同目录 `account-actions.sqlite3`，不公开分发。每次先落盘预留再请求，超时、断线、重启后不自动重发不确定操作；取消时也不能保证服务器还没收到请求。评论必须有真实评论编号、私信必须有消息编号才记为接口确认。可见性分别尝试匿名/登录抽样，未找到不等于发送失败，不能保证@通知已送达。不要删除记录来“试着重发”。

开启同仓库二次审阅时，B站配文与回评同样经过模型审阅，改写后复查；失败停止发送。@名单与接收者由代码固定。未开启二次审阅时不增加该模型调用。

## QQ分享（原功能保留）

开启刷B站后聊天里可请求搬屎或正常推荐，也保留 `/刷B站` 与 `/刷B站 兴趣词`。群聊遵守既有唤醒规则。面板勾选群/好友后开启定时分享，每个目标独立计时与去重，间隔独立于普通主动消息。一个目标失败不影响其他目标。

QQ分享经过已有发送前审阅和收件人校验；实际送达的最终文案进入当前会话持久化记忆，不带到其他会话或已重置会话。普通回复只发正文，不额外引用消息。

## 维护与验收

运行仓库 `python -m unittest discover -s tests`。自动测试模拟扫码成功/失效、Cookie隔离、账号切换、去重、撤销、私信模式、@解析、收藏归属与回评目标；不替用户发真实测试评论或私信。新部署需用户本人扫码，再用自己授权的收件人与视频验收账号写入；发布者未提供共享B站账号。若接口变化，应更新对应代码和测试，不能将成功HTTP状态当作成功发布。
