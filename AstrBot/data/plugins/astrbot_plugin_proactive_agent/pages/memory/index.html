功能开关

自主决策开启后：网站、阅读数量、下次时机、分享内容和对象由角色判断；聊天里的疑问与灵感会合并，空闲10秒后处理，至少间隔60秒重新考虑兴趣。可只读一篇结束，也可继续查证或只保存。传统阅读间隔、每日次数、网站白名单及普通定时闲聊机会不再控制这套流程，对方未回复和联系冷却不强制拦截（保留原自主模式设计）。每次最多8页、链接深度3层、实际运行10分钟；达到上限保存进度。明确必发任务、免打扰、可联系范围、正文真实性和投递防重继续有效；关闭开关即可恢复旧模式

预算、阅读范围与分享许可

传统模式要求网站白名单和每日请求预算；自主模式可搜索其他公开网站。直接读取单次10秒／2MB；贴吧使用专用阅读器（后台最长35秒），知乎使用已授权的普通 Edge 阅读扩展（最长65秒），传统模式每天最多50次正文请求，自主模式保留计数但不按此停读；视频仅抽样本机已取得的文件，最多9帧，不表示完整观看
